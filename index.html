ROS Web Video Streaming Guide

Learn how to stream ROS image topics to a web browser

Introduction Prerequisites Installation Usage Web Interface Troubleshooting

Introduction

This guide will show you how to set up web video streaming for ROS (Robot Operating System) image topics. With this setup, you can view your robot's camera feed or any image topic in a web browser without requiring special plugins or extensions.

The solution uses the web_video_server package, which provides HTTP streaming of ROS image topics in multiple formats including MJPEG, VP8, VP9, H264, and PNG.

Prerequisites

1ROS Installation

You need to have ROS installed on your system. This guide assumes you're using ROS Noetic (ROS 1) or ROS 2 Humble or newer.

2Basic ROS Knowledge

You should be familiar with basic ROS concepts like topics, nodes, and launching processes.

3Web Browser

A modern web browser that supports the video formats you plan to use (most modern browsers support MJPEG).

Note: The web_video_server package supports both ROS 1 and ROS 2. Make sure to use the appropriate instructions for your ROS version.

Installation

1Install web_video_server

You can install the web_video_server package using the following methods:

For ROS 2 (Humble, Jazzy, Rolling):

sudo apt install ros-$ROS_DISTRO-web-video-server

For ROS 1 (Noetic) or building from source:

# Create a workspace if you don't have one mkdir -p ~/ros_ws/src cd ~/ros_ws/src # Clone the repository git clone https://github.com/RobotWebTools/web_video_server.git # For ROS 1, switch to the ros1 branch git checkout ros1 # Install dependencies cd ~/ros_ws rosdep update rosdep install --from-paths src -i # Build the package colcon build --packages-select web_video_server source install/setup.bash

2Verify Installation

After installation, verify that the package is available:

# For ROS 2 ros2 pkg list | grep web_video_server # For ROS 1 rospack find web_video_server

Important: If you built from source, make sure to source your workspace setup file (source ~/ros_ws/install/setup.bash) in every terminal where you want to use the package.

Usage

1Start the Web Video Server

In a terminal, launch the web video server:

For ROS 1:

rosrun web_video_server web_video_server

For ROS 2:

ros2 run web_video_server web_video_server

By default, the server runs on port 8080. You can customize the port and other parameters:

# For ROS 1 rosrun web_video_server web_video_server _port:=8081 _address:=0.0.0.0 # For ROS 2 ros2 run web_video_server web_video_server --ros-args -p port:=8081 -p address:=0.0.0.0

2Publish Image Topics

Make sure you have a node publishing image topics. This could be a camera driver, simulation, or any node that publishes to image topics.

Common image topics include:

  • /camera/image_raw
  • /camera/rgb/image_raw
  • /camera/depth/image_raw
  • /usb_cam/image_raw

You can list available topics to find image topics:

# For ROS 1 rostopic list # For ROS 2 ros2 topic list

3Access the Web Interface

Open your web browser and navigate to:

http://localhost:8080

You should see a list of available image topics. Click on any topic to view the stream.

Note: If you're accessing the server from another device, replace localhost with the IP address of your ROS machine.

app.js

document.addEventListener('DOMContentLoaded', function() { const streamTypeSelect = document.getElementById('streamType'); const topicInput = document.getElementById('topicInput'); const widthInput = document.getElementById('widthInput'); const heightInput = document.getElementById('heightInput'); const qualityInput = document.getElementById('qualityInput'); const startButton = document.getElementById('startStream'); const stopButton = document.getElementById('stopStream'); const statusDiv = document.getElementById('status'); const streamImage = document.getElementById('streamImage'); let streamInterval = null; // Set default values widthInput.value = 0; heightInput.value = 0; qualityInput.value = 80; // Function to update the image stream function updateStream() { const topic = topicInput.value.trim(); if (!topic) { alert('Please enter a ROS topic'); return; } const type = streamTypeSelect.value; const width = widthInput.value; const height = heightInput.value; const quality = qualityInput.value; // Build the stream URL let streamUrl = `http://localhost:8080/stream?topic=${topic}&type=${type}`; if (width > 0) streamUrl += `&width=${width}`; if (height > 0) streamUrl += `&height=${height}`; if (quality > 0) streamUrl += `&quality=${quality}`; // Set the image source streamImage.src = streamUrl; statusDiv.textContent = `Connected to ${topic} (${type})`; statusDiv.className = 'status connected'; } // Start the stream startButton.addEventListener('click', function() { if (streamInterval) { clearInterval(streamInterval); } updateStream(); // For MJPEG, we don't need to refresh, but for other formats we might if (streamTypeSelect.value !== 'mjpeg') { streamInterval = setInterval(updateStream, 100); // Refresh every 100ms } }); // Stop the stream stopButton.addEventListener('click', function() { if (streamInterval) { clearInterval(streamInterval); streamInterval = null; } streamImage.src = ''; statusDiv.textContent = 'Stream stopped'; statusDiv.className = 'status disconnected'; }); // Handle image loading errors streamImage.addEventListener('error', function() { statusDiv.textContent = 'Error loading stream. Check if web_video_server is running and topic exists.'; statusDiv.className = 'status disconnected'; }); });

3Run the Web Interface

Open the index.html file in a web browser:

  • Double-click the file, or
  • Use a local web server for better functionality

Using Python Simple HTTP Server:

# Navigate to the directory containing your files cd ros-web-streaming # Python 3 python -m http.server 8000 # Python 2 python -m SimpleHTTPServer 8000

Then open http://localhost:8000 in your browser.

Troubleshooting

1Common Issues

No image topics available

Make sure you have a node publishing image topics. Verify with:

# For ROS 1 rostopic list # For ROS 2 ros2 topic list

Connection errors

Check that the web_video_server is running:

# For ROS 1 rosnode list # For ROS 2 ros2 node list

You should see /web_video_server in the list.

Can't access from other devices

Make sure to set the address parameter to 0.0.0.0 when starting the server:

# For ROS 1 rosrun web_video_server web_video_server _address:=0.0.0.0 # For ROS 2 ros2 run web_video_server web_video_server --ros-args -p address:=0.0.0.0

Also, check your firewall settings to ensure port 8080 is open.
